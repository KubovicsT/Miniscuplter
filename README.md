# Miniscuplter — Historical v0.4 Implementation Branch

This branch is an **internal historical development snapshot**, not a release target. It was used while the voxel/remesh geometry milestone that became `v0.4` was being implemented.

Use the preserved `v0.4` branch for the completed milestone and `v1.0` for current runtime testing and documentation.

## Branch policy

- feature code on this branch is frozen
- documentation may be corrected to prevent historical confusion
- do not use this branch as the basis for current builds or bug reports

See `docs/RELEASE_HISTORY.md` on `v1.0` for the complete release/development branch map.
