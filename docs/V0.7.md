# Miniscuplter v0.7 — Parts Library, Sockets & Kitbashing

v0.7 branches directly from the improved v0.6 rigging/posing build.

## Parts library

The new Kitbash tab provides a persistent per-user parts catalog under `user://parts_library`.

- import STL files into the reusable library
- save any selected scene object as a reusable part
- category filtering and text search
- compatible socket-type metadata
- add library parts back to the scene as separate editable objects
- starter procedural blockout parts: round base, horn, sword, shield and backpack

Categories currently include Head, Body, Armour, Weapon, Shield, Back, Base, Accessory, Creature and Generic.

## Typed sockets

Sockets are persistent project data. Current socket types include Generic, Head, Left/Right Hand, Left/Right Shoulder, Back, Waist, Base and Accessory.

Sockets can be:

1. placed directly on the selected object's visible surface with a viewport click, using the exact triangle hit position and normal;
2. generated as a starter set from the selected object's AABB, then replaced/refined manually.

When a rig exists, newly placed sockets are linked to the nearest rig joint and store a joint-local offset. This allows their world position to follow the current pose.

## Snapping

Select a separate scene part, select a socket, then use **Snap Selected Object**.

The part remains non-destructive and separate. It is aligned so its local +Y direction follows the socket normal. Fine transform adjustments remain available before final voxel union/remesh.

Attachment records can be detached without deleting the object.

## Pose following

Socket-linked parts are refreshed on a short timer. Rig-linked sockets therefore update while the character is posed, and attached weapons/accessories move with them.

This is intentionally separate from the character's skin weights: rigid parts remain rigid.

## Project format

`.msculpt` project version is now 4 and stores:

- mesh objects and roles
- AI edit layers
- rigs/joints
- sockets
- socket attachment links

The reusable global parts catalog itself is not embedded into each project; project meshes are still saved into the normal project asset sidecar so a saved project remains self-contained.

## v0.6 improvements inherited by v0.7

Before branching v0.7, v0.6 was improved with:

- bone-segment-based skin influence rather than simple nearest-joint weighting
- up to four normalized joint influences per vertex
- cached weights for faster repeated pose previews
- direct viewport joint picking and dragging
- optional two-bone IK while dragging an end joint

## Limitations / next refinements

- imported parts currently use their existing mesh origin as the snap/mount origin; a dedicated mount-point editor is a future refinement
- automatic starter sockets are approximate and should be surface-corrected for unusual anatomy
- socket orientation currently uses a normal vector rather than a full authored tangent frame, so roll may need manual adjustment
- no thumbnail renderer/cache yet; the library is text-first in this milestone
- no curated copyrighted commercial part pack is bundled
- v0.7 does not automatically voxel-union snapped parts; the existing v0.4 geometry tools remain the explicit destructive bake step
