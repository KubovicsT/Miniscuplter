# Miniscuplter v0.8 — Advanced Sculpting

v0.8 is the advanced-sculpting milestone, branched directly from the refined v0.7 kitbash release.

## Added

- X/Y/Z object-local symmetry, including combinations of axes.
- Sculpt protection masks with paint, erase, mask-all, clear and invert operations.
- Procedural brush alpha presets: None, HardCenter, Pinpoint, Ring and Noise.
- Falloff presets: Smooth, Linear, Sharp and Dome.
- New brushes: Pinch, Scrape, Clay and SnakeHook, alongside Draw, Smooth, Inflate, Grab, Crease and Flatten.
- Live viewport brush cursor aligned to the actual mesh surface.
- Manual detail remesh from the Sculpt v0.8 panel.
- Optional periodic remesh every 12 completed sculpt strokes.
- Existing 30-step sculpt undo remains active for mesh-changing strokes.
- Remesh jobs use the hardened v0.5.5 cancellation/error plumbing and the existing v0.4 voxel backend.

## Workflow

1. Select a mesh.
2. Choose any sculpt brush from the original Sculpt selector.
3. Configure radius/strength with the original controls.
4. In `Sculpt v0.8`, choose symmetry axes, falloff and alpha.
5. Optionally paint a protection mask; masked vertices reduce or block brush deformation.
6. Sculpt normally with LMB.
7. Use `Remesh Selected Now` when topology becomes stretched, or enable periodic remesh.
8. Continue sculpting after the remesh.

## Important implementation notes

- v0.8 keeps the original v0.1 viewport input loop. A backwards-compatible SculptEngine override hook routes those strokes through the v0.8 engine, avoiding invasive changes to older editor code.
- Symmetry planes pass through the selected object's local origin. Center objects appropriately before symmetry-sensitive sculpting.
- Sculpt masks are vertex-based. A voxel remesh changes topology, so the mask is deliberately cleared after remeshing rather than being incorrectly mapped to unrelated vertices.
- The current alpha system is procedural. User-imported grayscale alpha textures remain future work.
- Periodic remesh is not per-triangle dynamic topology. It is a CPU voxel topology refresh using the existing geometry backend; very small voxel sizes can be expensive on RAM/CPU.
- SculptEngine currently operates on surface 0 of an ArrayMesh, matching the existing sculpt architecture. Typical STL imports are a single triangle surface.
- Runtime feel/performance still requires testing on representative high-poly miniatures; CI only proves compilation and Python syntax.

## Suggested runtime test

- Starter sphere with X symmetry enabled.
- Draw/Clay/Scrape/Pinch on both sides of the model.
- Paint half the face/body with a protection mask and verify brushes no longer move protected areas.
- Test HardCenter, Pinpoint, Ring and Noise alpha presets.
- Test SnakeHook with a moderate radius and low strength.
- Undo/redo several strokes.
- Run a 0.28 mm remesh and continue sculpting.
- Test periodic remesh on a disposable mesh before using it on a detailed project.
