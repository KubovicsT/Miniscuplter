# Miniscuplter v0.5

v0.5 is based on v0.4 and keeps all previous release branches untouched.

## Main milestone

AI edit placement and user-facing generation jobs.

## Added

- Preview / Standard / High quality presets for local 2D generation and Hunyuan3D shape generation.
- Learned generation-time estimates stored per hardware profile, operation and quality preset.
- Recent-range ETA display based on successful local runs.
- Resettable job-history store under the Godot user data directory.
- Paintable viewport AI mask with erase and adjustable radius.
- Four low-cost preview candidates before committing to 3D generation.
- Candidate selection as the approved 2D source.
- First AI patch anchor: the first painted point on the selected mesh is raycast into 3D and the generated patch is placed at that anchor.
- Generated patches are named as separate `AI Edit Layer` scene objects so they remain non-destructive until voxel union/remesh.

## Quality mapping

### 2D Stable Diffusion
- Preview: 384 px / 12 steps
- Standard: 512 px / 24 steps
- High: 640 px / 36 steps

### Hunyuan3D shape
- Preview: 18 inference steps
- Standard: 30 inference steps
- High: 45 inference steps

Provider fallbacks keep their compatibility behavior where exact quality parameters are not exposed.

## ETA behavior

The first run for an operation/quality/hardware combination reports that no personal history exists. Successful runs are recorded and the UI then shows a weighted recent estimate plus a recent observed range. Hardware identity includes GPU name, detected VRAM and Miniscuplter hardware profile so a GPU upgrade does not reuse stale timings.

## Current limitations

- The patch anchor is a first-pass placement system; it does not yet infer full orientation and scale from depth/normals.
- Progress percentage is not fabricated when a provider has no reliable progress callback; v0.5 focuses on elapsed duration and learned ETA.
- Candidate generation currently runs four preview edits sequentially.
- Painted masks are stored as viewport-resolution grayscale PNGs.
- AI Edit Layers are named scene objects rather than a fully persisted typed layer hierarchy in the project format.
