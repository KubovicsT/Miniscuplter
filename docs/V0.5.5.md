# Miniscuplter v0.5.5

v0.5.5 is a stabilization/completion branch created directly from the corrected v0.5 head. Earlier release branches remain unchanged.

## Purpose

Finish the most important incomplete infrastructure from v0.1–v0.5 before adding auto-rigging/posing in v0.6.

## Added / completed

- Enhanced geometry-context capture writes RGB, a geometry-derived depth buffer, and world-space normal buffer plus depth metadata.
- AI patch anchoring now records the actual triangle surface normal at the painted point.
- Generated patches receive an initial normal-aligned orientation and scale estimate from selected-object size + painted mask coverage.
- AI edit layers now have persisted metadata in `.msculpt` project version 2: source object, prompt, quality, source image, mask, anchor, normal, initial scale and creation time.
- Save/load restores the AI edit-layer metadata alongside mesh objects.
- User-requested cancellation can abort the current HTTP request immediately and candidate sets stop between generations. Providers that do not expose cooperative interruption may still finish an internal inference step server-side.
- Starting-image preprocessing now normalizes to RGB, safely flattens alpha over neutral gray, downsizes oversized inputs to a maximum 2048-pixel side, and clears stale approved-source state correctly.
- Voxel remesh validates file existence, triangle content and finite coordinates before processing.
- Voxel remesh estimates occupancy-grid size and stops dangerous jobs above a configurable memory-safety threshold with a suggested larger voxel pitch.
- Geometry API returns clearer 400/413 errors for invalid or memory-dangerous jobs.
- Basic mesh validation reports triangle count, open edges and non-manifold edges using a quantized edge-incidence test.
- Two-minute autosave writes a recovery `.msculpt` project under the Godot user data directory.
- A precise normal-offset control helps fine-tune AI patches after automatic placement.
- AI component installation checks available disk space before starting large model downloads and reports free/total disk information in component status.

## What remains intentionally outside v0.5.5

- Full skeleton generation, skinning and posing are v0.6.
- Hero-Forge-style parts/sockets are later work.
- Full print repair, wall-thickness heatmaps and self-intersection repair remain later printability milestones.
- The current voxel backend is still CPU/trimesh rather than the future native SDF/OpenVDB backend.
- Cancellation is fully immediate on the Miniscuplter client side; hard interruption inside every third-party model provider depends on provider support.
- The depth/normal capture is geometry-derived at a bounded resolution for predictable memory/performance rather than a renderer-specific GPU depth attachment.

## Recommended runtime test

1. Load or generate a miniature.
2. Paint an AI mask and confirm a surface anchor is acquired.
3. Capture RGB + Depth + Normals and inspect the generated context files.
4. Generate four preview candidates, cancel once during a test, then complete another set.
5. Select a candidate and generate a 3D patch.
6. Verify position, surface-normal orientation and approximate scale.
7. Save the project, reload it and confirm the patch object and AI-layer metadata survive.
8. Validate the patch/source mesh for open/non-manifold edges.
9. Voxel-union the objects at a safe pitch and deliberately test a too-small pitch to confirm the memory guard.
10. Leave the app open long enough to confirm recovery autosave is written.

CI verifies Windows .NET compilation and Python backend syntax. Local model inference and GPU-memory behavior still require a real-machine runtime test.
