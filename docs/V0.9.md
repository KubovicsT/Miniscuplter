# Miniscuplter v0.9 — Printability + Repair

v0.9 focuses on preparing a finished miniature for STL export and slicer validation.

## Structural analysis

The backend now reports:

- vertex and triangle counts
- model bounds and surface area
- watertight state
- winding consistency
- open edge count
- non-manifold edge count
- connected shell count
- degenerate face count
- volume when the mesh is closed

These are structural mesh checks rather than guesses.

## Heuristic warnings

Two additional diagnostics are deliberately labelled heuristic:

- minimum-feature warning based on triangle altitude below a configurable threshold
- possible self-intersection candidates based on non-adjacent triangle AABB overlap

Neither is presented as true wall-thickness or exact self-intersection analysis. Final slicer validation is still required.

## Repair

Repair Selected uses the existing memory-guarded filled voxel reconstruction. It can close holes, merge overlaps and remove many non-manifold conditions, but it is destructive and may soften details smaller than the chosen voxel pitch.

The pre-repair mesh is pushed to undo before replacement.

## Printable scene bake

Bake Entire Scene exports all scene meshes in world coordinates, unions them through filled voxel reconstruction and adds the result as a new `Printable Bake v0.9` object. Original objects remain unchanged.

This is useful after posing, attaching parts and sculpting, when a single printable shell is wanted.

## Reports

Analysis results are shown in the editor and can be saved as JSON.

## Limitations

v0.9 does not provide exact wall-thickness ray analysis, exact triangle/triangle self-intersection testing, automatic support generation or slicer-level print simulation. These remain areas for later refinement or external slicer validation.
