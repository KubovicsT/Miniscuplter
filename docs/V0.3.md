# Miniscuplter v0.3

v0.3 is based directly on the `v0.2` branch and preserves both earlier versions unchanged.

## New in v0.3: user-supplied starting images

The AI workflow no longer requires Miniscuplter to generate the first concept image.

Users can choose **Use My Image** in the AI panel and load their own artwork or reference image from disk. Supported formats are PNG, JPEG, WebP and BMP.

The selected image is copied into Miniscuplter's user workspace as PNG and becomes the current approved 2D source. From there the user can:

1. Generate 3D directly from the uploaded image.
2. Enter a prompt and use **Edit Starting Image With AI** before 3D generation.
3. Continue iterating on the 2D result and only generate 3D once satisfied.
4. Clear the custom source and return to the AI-generated concept / viewport-capture workflow.

This means the full starting flow is now:

```text
AI-generated concept ─┐
                      ├─> approved 2D source -> optional AI edit -> 3D generation
User artwork/image ───┘
```

The uploaded source remains local unless it is explicitly passed to a configured AI provider by the user.

## Version separation

- `main` = v0.1 baseline
- `v0.2` = managed local AI components
- `v0.3` = v0.2 + user-supplied starting image workflow

Do not merge branches while comparative testing is underway.
